# device_samsung_gts6l (Galaxy Tab S6 LTE, SM-T865) - para OrangeFox 12.1

Generado a partir del recovery STOCK (Android 12, parche 2023-08, kernel 4.14.190).

Tomado tal cual del recovery stock: kernel, dtbo, cabecera v1, offsets
(ramdisk 0x02000000, tags 0x01e00000), board SRPSC20B006, cmdline.
Tomado del TWRP que ya funcionaba: recovery.fstab y ruta de brillo.

Supuestos (revisar si algo falla): variante de CPU generic, flags TW_*/OF_*,
tema portrait_hdpi (la rotacion puede verse mal), tamano de particion recovery
deducido del tamano de la imagen stock, descifrado de /data NO garantizado.
